# Portfolio Website

Personal portfolio of **Randhir Singh** — MERN Stack & React Native Developer, New Delhi.

🌐 **Live:** https://randhirsingh77.github.io/portfolio/

## About

A hand-built, fully responsive portfolio with a dark theme, scroll-reveal animations,
a typewriter hero and a mobile hamburger menu. No frameworks and no build step —
plain HTML, CSS and JavaScript, hosted on GitHub Pages.

## Run locally

Open `index.html` in a browser, or:

```bash
npx serve .
```
